# Third-party notices

Multiverse integrates and depends on open-source software including:

- Flagsmith server, Python SDK, and flag engine — BSD-3-Clause.
- FastAPI, Pydantic, SQLAlchemy, Alembic, Uvicorn, HTTPX — permissive open-source licences.
- Playwright — Apache-2.0.
- AllPairsPy — MIT.
- NetworkX, NumPy, and scikit-learn — BSD-family licences.
- Cryptography — Apache-2.0/BSD.
- React, Vite, Three.js, React Three Fiber, React Flow, GSAP, Recharts, Tailwind CSS, Motion, and Lucide — their respective open-source licences.
- Geist fonts — SIL Open Font License 1.1; the licence text is included in `public/fonts/OFL-Geist.txt`.

This file is a summary, not a replacement for dependency licence texts. Distribution builds should retain all notices required by their pinned dependency versions.
